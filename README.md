# Breevi Privacy Policy

**Last Updated:** September 27, 2025  
**For App Version:** 0.1.2  
*This privacy policy applies only to the Android version of Breevi distributed via Google Play.*

---

## What Data Is Collected?

We do not collect, store, or process any personal data from users. However, Google Play Console automatically collects anonymous usage analytics on our behalf, including:

- Device model, OS version, and screen size
- App version, installation source, and update history
- Session duration, feature usage, and crash reports

**Important clarification:**  
No personally identifiable information (PII) is collected (e.g., no email, name, location, or device identifiers like IMEI).

---

## Why Is This Data Collected?

Google Play Console uses this data exclusively to:
- Fix crashes and technical issues
- Understand how users interact with the App
- Improve future updates (e.g., identifying underused features)

---

## How Is Data Used?

- All data is **aggregated and anonymized** by Google
- We **never access individual user data** or track specific users
- Data is **not shared with third parties** beyond Google's standard Play Console processing

---

## Google's Role

- Google processes this data under its [Google Play Console Privacy Policy](https://policies.google.com/privacy)
- We have **no control** over how Google collects or uses this data
- We do not request additional data beyond Play Console's default analytics

---

## Changes to This Policy

Should we ever implement new data collection methods (e.g., ads or user accounts), we will:
1. Update this policy with a new "Last Updated" date
2. Notify users through Google Play Store listing updates
3. Provide 30 days' notice before implementing changes
